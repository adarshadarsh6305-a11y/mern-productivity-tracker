# Productivity Tracker Chrome Extension

A MERN Stack based Productivity Tracker Chrome Extension that helps users monitor website usage, block distracting websites, and analyze productivity through a React dashboard.

## Features

* Website Time Tracking
* Website Blocking
* Productivity Score Calculation
* Daily Activity Monitoring
* React Dashboard
* MongoDB Atlas Integration
* Express REST APIs
* Chrome Extension Integration

## Technologies Used

### Frontend

* React.js
* CSS
* Axios

### Backend

* Node.js
* Express.js
* MongoDB Atlas
* Mongoose

### Chrome Extension

* Manifest V3
* Background Scripts
* Chrome Tabs API

## Project Structure

productivity-tracker

├── client

├── server

└── extension

## Installation

### Backend

```bash
cd server
npm install
node index.js
```

### Frontend

```bash
cd client
npm install
npm start
```

### Chrome Extension

1. Open Chrome
2. Visit chrome://extensions
3. Enable Developer Mode
4. Click Load Unpacked
5. Select the extension folder

## Key Functionalities

* Tracks time spent on websites
* Stores activity data in MongoDB Atlas
* Blocks user-defined distracting websites
* Displays productivity statistics
* Provides productivity score analysis
